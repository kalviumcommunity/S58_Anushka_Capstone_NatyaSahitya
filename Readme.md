# NatyaSahitya

A comprehensive platform dedicated to preserving and promoting the rich heritage of Indian classical dance forms.

## About the Project

NatyaSahitya is a website showcasing different types of classical dance forms in India. It provides detailed information about 9 classical dance forms, including their history, theory, and practical aspects. Users can access premium content after logging in, and can also share their dance videos on the platform.

## Key Features

- Explore 9 classical dance forms of India
- Access detailed information about each dance form's history and cultural significance
- Learn theory and practical aspects through chapter/stage-wise content
- User authentication system for accessing premium content
- Video sharing capabilities for dancers
- Responsive design with cultural elements and animations

## Project Structure

The project is divided into two main parts:

### Backend
- Node.js with Express.js
- MongoDB database
- User authentication
- API endpoints for data retrieval

### Frontend
- React.js with Vite
- Responsive design with animations
- Cultural heritage theme
- Interactive UI components
